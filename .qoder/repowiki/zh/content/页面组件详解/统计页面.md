## 简介
本文件面向统计页面（明细页）的完整技术文档，聚焦历史记录展示与时间筛选功能，涵盖：
- 按日期分组、记录排序与数据过滤算法
- 页面数据获取机制、分页加载与性能优化策略
- 用户交互事件处理、筛选条件设置与结果显示逻辑
- 数据可视化方案与图表集成方法
- 实际代码实现与使用示例

统计页面以"本地存储"为核心数据源，通过时间筛选器控制显示范围，并对记录进行分组与汇总，最终在视图层以卡片化列表呈现。**新增的月筛选功能**允许用户按年份和月份精确查看历史数据，**测试数据初始化系统**为开发者提供了丰富的演示数据。

### 时间筛选与数据过滤算法
- 筛选模式
  - 全部：不过滤，直接进入排序与分组
  - 今天：按日期字符串精确匹配
  - 本周：计算周起始时间（周日 00:00:00），筛选大于等于该时间的记录
  - 本月：计算月起始时间（1号 00:00:00），筛选大于等于该时间的记录
- **新增** 月度筛选逻辑
  - 同时匹配年份和月份，确保精确的数据范围
  - 与月份选择器功能配合使用
- 排序规则
  - 按日期+时间降序排列，确保最新记录在前
- 复杂度
  - 过滤 O(n)，排序 O(n log n)，整体 O(n log n)

```mermaid
flowchart TD
Start(["开始"]) --> GetToday["获取今日日期并清零时分秒"]
GetToday --> Mode{"筛选模式"}
Mode --> |全部| Pass["不执行过滤"]
Mode --> |今天| Today["提取今日日期字符串<br/>按日期字段过滤"]
Mode --> |本周| Week["计算周起始时间<br/>按日期>=周起始过滤"]
Mode --> |本月| Month["计算月起始时间<br/>按日期>=月起始过滤"]
Mode --> |年月| YearMonth["按年份和月份过滤<br/>精确匹配"]
Pass --> Sort["按日期+时间降序排序"]
Today --> Sort
Week --> Sort
Month --> Sort
YearMonth --> Sort
Sort --> End(["返回过滤后的记录"])
```

### 按日期分组与结果聚合
- 分组策略
  - 以 record.date 为键进行分组，形成 {date: [records]} 的映射
  - 对日期键进行降序排序，确保日期新到旧
- 分组项内容
  - date：原始日期字符串
  - dateText：格式化为"月日 星期"
  - records：该日的所有记录
  - dayExpense：当日结余（收入-支出）
- 复杂度
  - 分组 O(n)，排序 O(d log d)，聚合 O(n)，整体 O(n log n)

```mermaid
flowchart TD
GStart(["开始"]) --> Group["遍历记录按日期分组"]
Group --> Keys["获取所有日期键并降序排序"]
Keys --> Map["逐个日期计算当日结余"]
Map --> Build["构建分组项对象"]
Build --> GEnd(["返回分组结果"])
```

## 性能考虑
- 内存与时间复杂度
  - 筛选：O(n)
  - 排序：O(n log n)
  - 分组：O(n)
  - 月度统计：O(n)
  - 整体：O(n log n)
- 优化建议
  - 避免重复读取本地存储：在单次页面生命周期内缓存 records
  - 减少 setData 次数：合并多个字段更新
  - 列表渲染优化：使用 wx:for 与 wx:key，避免大列表全量重排
  - **新增** 月份选择器优化：使用临时值预览，确认后再更新
  - 图表集成：按需渲染，避免在切换筛选时重复计算图表数据
- 分页加载
  - 当前未实现分页；如数据量增长，可在分组结果上做虚拟滚动或分段渲染

## 故障排查指南
- 无记录显示
  - 检查本地存储是否存在 records 键，必要时由应用初始化写入空数组
  - **新增** 确认测试数据是否正确初始化
  - 确认筛选模式是否过严（例如"本周/本月"导致无数据）
  - **新增** 检查月份选择器是否正确设置年份和月份
- 金额显示异常
  - 确保金额字段为数值类型，避免字符串拼接导致排序错误
  - 检查分组时的正负号逻辑与格式化精度
- 图标不显示
  - 确认分类名称与图标映射表一致
- 交互无效
  - 检查事件绑定与 data-* 属性是否正确传递
  - 确认页面生命周期钩子已触发数据加载
  - **新增** 检查月份选择器的事件绑定和数据更新逻辑
